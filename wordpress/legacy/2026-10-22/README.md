# Ancien WordPress — 22 octobre 2026

Copie visuelle de l'accueil public, réalisée avant l'activation du thème Studio
JDS. `index.html` conserve le contenu et la mise en page présents dans le DOM ;
`accueil-avant-migration.jpg` montre l'apparence constatée. Les formulaires et les
actions de commande sont désactivés. Les sessions WordPress et les scripts ne
sont pas inclus.

Cette copie **n'est pas une sauvegarde complète de WordPress** : les images et
feuilles de style sont encore référencées sur leur hébergement d'origine. Elle
ne contient ni la base de données, ni les comptes, ni les commandes, ni les
fichiers PHP de l'ancien thème et des extensions.

L'ancien thème JDS (`alukas`), ses réglages et son contenu restent sur
l'hébergement WordPress. Pour rétablir l'ancien rendu, réactiver le thème JDS
dans Apparence → Thèmes. Le nouveau thème ne supprime pas ces données.

Une exportation complète All-in-One WP Migration a également été lancée sur
l'hébergement. Son résultat doit être vérifié dans la section Sauvegardes ;
elle n'est pas contenue dans ce dossier public.
